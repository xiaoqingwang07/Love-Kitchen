# 上线部署清单（需要账号凭证，代码侧已就绪）

> 代码、类型检查、回归测试、构建均已通过。以下步骤依赖你的账号，按顺序做完即可提审。
> 详细操作见 README 对应小节。

## 第 1 步 · Vercel（约 20 分钟）

- [ ] 把仓库导入 Vercel，部署 4 个 serverless 函数（`api/` 目录自动识别）
- [ ] 注册 [Upstash](https://upstash.com/) 免费 Redis，拿到 REST URL 和 Token
- [ ] 在 Vercel 环境变量里配置：
  - `MINIMAX_API_KEY`（AI 菜谱 / 拍照识别的命脉）
  - `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`（家庭同步 + 临期提醒）
  - `WX_APPID` / `WX_SECRET`（临期提醒推送）
  - `CRON_SECRET`（随机串，保护定时任务）

## 第 2 步 · catalog CDN（约 10 分钟）

- [ ] 把 `catalog-cdn/` 目录（约 19MB）整体上传到 CDN 或微信云开发·静态托管，保持目录结构
- [ ] 不配也能上线（回退内置 200 道），但强烈建议配

## 第 3 步 · 微信公众平台（约 15 分钟）

- [ ] 订阅消息：选一个含「名称/日期」字段的模板，记下 `template_id`，按字段名核对 `api/reminder-cron.js` 的 `buildTemplateData`
- [ ] 插件管理：添加「微信同声传译」插件（appid `wx069ba97219f66d99`），并把版本号填进 `src/app.config.ts`（语音搜索/入库从降级态变成真 ASR）
- [ ] 服务器域名（request）：你的 Vercel 域名、`api.open-meteo.com`、catalog CDN 域名
- [ ] 服务器域名（downloadFile）：`i2.chuimg.com`、`images.unsplash.com`

## 第 4 步 · 客户端构建变量（`.env.local`）

```
TARO_APP_LLM_PROXY_URL=https://你的项目.vercel.app/api/llm-proxy
TARO_APP_REMINDER_API_URL=https://你的项目.vercel.app/api/reminder-register
TARO_APP_HOUSEHOLD_API_URL=https://你的项目.vercel.app/api/household-sync
TARO_APP_EXPIRY_TMPL_ID=你的订阅消息模板id
TARO_APP_CATALOG_BASE_URL=https://你的cdn域名/love-kitchen/catalog
```

- [ ] 配完执行 `npm run verify:all`，全绿后用微信开发者工具上传体验版

## 第 5 步 · 真机内测一周（关键）

- [ ] 找 3–5 个真实家庭（最好是会一起买菜做饭的），拉体验版
- [ ] 每天看埋点（我的 → 关于连点 7 次 → 开发者选项 → 复制埋点）重点盯：
  - `first_intake_done`：首次入库转化率（录入是生死线）
  - `meal_solved`：晚餐闭环次数（北极星）
  - `dish_vision_fail` / 识别修正率：拍照识别可用性
- [ ] 收集「小票一拍到全部入库」的实际秒数，超过 30 秒就要继续打磨入库流程

## 中期必办（不阻塞上线，阻塞商业化）

- [ ] **图床迁移**：菜谱图目前外链下厨房（`i2.chuimg.com`），有防盗链和版权风险，商用前必须自有化。执行 `scripts/图床迁移说明.md`
- [ ] 微信认证 + 类目（生活服务-菜谱类）
