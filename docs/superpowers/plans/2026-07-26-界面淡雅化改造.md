# 界面淡雅化改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把爱心厨房的界面从「冷白鲜绿 + 排版缺陷」改造成「淡雅暖色 + 强层次」，同时修掉 6 项已核实的排版缺陷。

**Architecture:** 改动集中在设计变量层（`src/theme/designTokens.ts`，57 个文件引用，改一处全局生效）与全局样式层（`src/app.scss`）。图标走「SVG 源文件 → qlmanage 栅格化 → PIL 裁切归一 → PNG」新管线，替换现有依赖字体渲染的坏管线。首页按已确认的方案 A 重构，其余 4 屏仅套用新规则不改结构。

**Tech Stack:** Taro 3 + React + MobX + TypeScript；样式为 TS 内联 `CSSProperties` 对象；图标生成用 Node + macOS `qlmanage` + Python PIL；验证用 `npm run verify:all`（含 `scripts/regression-checks.mjs` 的 98 条源码断言）。

`scripts/generate-icons.mjs`：

```js
#!/usr/bin/env node
/**
 * 图标管线：SVG 源 → qlmanage 栅格化 → PIL 裁切归一/上色 → PNG
 * 不依赖字体（旧脚本 generate-app-icons.mjs 因 PIL 无法打开 PingFang.ttc 而产出坏图标）
 * 运行：node scripts/generate-icons.mjs
 */
import { execFileSync } from 'node:child_process'
import fs from 'node:fs'
import os from 'node:os'
import path from 'node:path'

const root = process.cwd()
const srcDir = path.join(root, 'scripts/icons/src')

/** name -> { out: 输出路径, color: 描边色, size: 边长(px) } */
export const TARGETS = {
  search: [{ out: 'src/assets/icons/search.png', color: '#BEB6AE', size: 144 }],
}

const py = `
import json, sys, os
from PIL import Image

specs = json.loads(sys.argv[1])
for s in specs:
    img = Image.open(s['raw']).convert('RGBA')
    # qlmanage 会在方形画布内留白，先按 alpha 裁到内容边界
    bbox = img.getbbox()
    if bbox:
        img = img.crop(bbox)
    # 等比缩放进 size*0.82 的内容区，再居中贴到透明方形画布
    size = s['size']
    inner = int(size * 0.82)
    w, h = img.size
    scale = min(inner / w, inner / h)
    img = img.resize((max(1, int(w * scale)), max(1, int(h * scale))), Image.LANCZOS)
    canvas = Image.new('RGBA', (size, size), (0, 0, 0, 0))
    canvas.paste(img, ((size - img.size[0]) // 2, (size - img.size[1]) // 2), img)
    # 用 alpha 作蒙版重新上色，保证描边色完全可控
    c = s['color'].lstrip('#')
    rgb = (int(c[0:2], 16), int(c[2:4], 16), int(c[4:6], 16))
    solid = Image.new('RGBA', canvas.size, rgb + (255,))
    out = Image.new('RGBA', canvas.size, (0, 0, 0, 0))
    out.paste(solid, (0, 0), canvas.split()[3])
    os.makedirs(os.path.dirname(s['out']), exist_ok=True)
    out.save(s['out'])
print(len(specs))
`

export function build(targets = TARGETS) {
  const tmp = fs.mkdtempSync(path.join(os.tmpdir(), 'lk-icons-'))
  const specs = []
  for (const [name, outs] of Object.entries(targets)) {
    const svg = path.join(srcDir, `${name}.svg`)
    if (!fs.existsSync(svg)) throw new Error(`缺少 SVG 源文件：${svg}`)
    execFileSync('qlmanage', ['-t', '-s', '512', '-o', tmp, svg], { stdio: 'ignore' })
    const raw = path.join(tmp, `${name}.svg.png`)
    if (!fs.existsSync(raw)) throw new Error(`qlmanage 未产出：${raw}`)
    for (const o of outs) {
      specs.push({ raw, out: path.join(root, o.out), color: o.color, size: o.size })
    }
  }
  execFileSync('python3', ['-c', py, JSON.stringify(specs)], { stdio: 'inherit' })
  fs.rmSync(tmp, { recursive: true, force: true })
  console.log(`Generated ${specs.length} icons`)
}

build()
```
